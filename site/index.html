HOP AI

AI와 함께 쓰는 HWP 편집기

HOP AI는 오픈소스 HWP 편집기 HOP에 AI 편집 도우미를 더한 macOS, Windows, Linux용 데스크톱 앱입니다.

  • 말로 쓰고 고치기 — "사업계획서 초안 써줘", "표의 합계 행 추가해줘"처럼 지시하면 본문·표·서식을 HWP 문서에 바로 씁니다.
  • 문서 위에서 검토 — 바뀐 문단이 강조되고, 변경마다 승인하거나 거절합니다.
  • 원하는 모델로 — Claude·GPT·Gemini API 키, 로컬 Ollama, 또는 이미 쓰는 Claude Code 구독(키 없이)으로 동작합니다.

최신 버전 다운로드

최신 릴리즈 파일로 연결됩니다.

macOS

Apple Silicon .dmg Intel .dmg

개발자 서명 없이 배포하는 앱이라 처음 열 때 경고가 뜹니다. 응용 프로그램 폴더로 옮긴 뒤 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 눌러 주세요. "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 아래를 한 번 실행하면 됩니다. xattr -dr com.apple.quarantine "/Applications/HOP AI.app"

Windows

x64 .msi x64 .exe setup

서명되지 않은 앱이라 다운로드나 실행 중 보안 경고가 표시될 수 있습니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러 주세요. Edge에서 "일반적으로 다운로드되지 않습니다"가 표시되면 다운로드 항목의 ... 메뉴에서 유지를 선택해 주세요.

Linux

x64 .deb (권장) Debian/Ubuntu x64 .rpm Fedora/openSUSE arm64 .deb Debian/Ubuntu AppImage 독립 실행형

한글 IME 안정성을 위해 배포판에 맞는 .deb 또는 .rpm 패키지를 먼저 사용해 주세요. arm64 Linux는 Debian/Ubuntu 계열 .deb를 먼저 지원합니다. AppImage는 독립 실행형 배포물이며, 일부 Linux 환경에서는 작동이 불안정할 수 있습니다.

HOP AI는 HOP와 rhwp를 기반으로 합니다. 앱과 HWP 엔진을 공개해 주신 개발자분들께 감사드립니다.
